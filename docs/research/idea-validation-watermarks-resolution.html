Watermark-like cues and resolution-aware inference

Do hallucinated watermarks provide a useful AIGC signal, and should detector capacity be routed by image resolution? The short answer is “watermarks only as a controlled auxiliary cue” and “yes to adaptive processing, but not a raw low/high-resolution switch.”

Executive verdict

Both brainstorms point at real phenomena, but the literal implementations would create avoidable shortcuts.

Medium confidence Watermark cue: experiment only

A visible, hallucinated signature/logo can be evidence in a particular image, but training watermark = AI invites false positives on authentic stock photography and false negatives after cropping, inpainting, or generator changes. The image literature directly treats provider overlays as an easily learned confound; direct validation for hallucinated fake watermarks as a general detector feature was not found in this search.

Medium-high confidence Adaptive resolution: pursue with changes

High-resolution native tiles preserve forensic detail that fixed resizing destroys, and coarse-to-fine conditional inference is well established. Route by effective quality and model uncertainty, not file dimensions alone. A high-pixel-count screenshot may contain little native detail; a low-resolution sample may be the hard case that needs the more robust model.

Challenge constraint. The organizer brief says SynthID is not to be relied on and its test handling is ambiguous. Any watermark-derived feature must be optional and must not define the final decision. Dimensions and codecs must also be label-balanced because size/compression shortcuts are already documented in AIGC benchmarks [W2].

First untangle “watermark”

The chat idea can mean four technically different signals. Only the first is the proposed hallucination heuristic.

Hallucinated visible mark

Gibberish signature, stock-photo-like overlay, malformed logo, or text rendered as scene content. Passive semantic/artifact cue; no decoder or key exists.

Provider visible overlay

A service intentionally stamps a logo or label after generation. Trivial to classify, trivial to crop, and strongly correlated with one source.

Embedded watermark

An intentional, usually imperceptible pixel signal such as a learned watermark. Detection uses a provider-specific decoder/key and is proactive provenance, not passive forensics.

Metadata / provenance

EXIF or signed manifests such as content credentials. Useful provenance evidence, but separable from what can be inferred from pixels and often lost during redistribution.

Defensible use

  • Run OCR/logo/signature detection as an explanation tag or error-analysis feature.
  • If it improves prediction after counterfactual testing, fuse only a bounded auxiliary representation while training for invariance to ordinary overlays.
  • Report an actual decoded watermark through a separate provenance field in a future interface, if rules allow; do not silently equate it with the passive AIGC score.

Failure modes to expect

  • Mark-to-frame: authentic stock images, news photos, memes, artwork, or signed photography become false positives.
  • Strip-to-evade: crop, inpaint, blur, re-screenshot, or simple overlay removal flips an AIGC image toward real.
  • Generator drift: newer generators render text correctly or produce no mark.
  • Source leakage: the cue identifies a website/product pipeline rather than generated provenance.

Important reversal. The proposed rule “low res → cheap, high res → powerful” may allocate the least compute to the least informative images. High-resolution images offer more native patches, but may be cheaply resolved by one or two texture-rich crops. Low-resolution, compressed images can require the robust semantic/phase model precisely because fragile local traces are gone. Let uncertainty and measured effective quality arbitrate.

Recommended hackathon architecture

Build a small adaptive cascade around models the team should benchmark anyway. Keep a single calibrated AIGC output.

1 · Cheap audit + glanceRead width/height/codec; estimate blur, JPEG quality and texture energy; run a lightweight full-frame model plus 1–2 native patches.
→
2 · Confidence gateExit only when the cheap score is calibrated and stable across a mild resize/JPEG consistency view. Dimensions affect the patch budget, not the label.
→
3 · Focus + fuseFor uncertain samples, aggregate more texture-diverse native tiles with the stronger VFM/LoRA or phase-aware branch, then produce one calibrated score.

Router inputs

  • Cheap-model logit, entropy/margin, and disagreement across transformed views
  • Shortest side, megapixels, and aspect ratio
  • Estimated JPEG quality, blur/effective resolution, and high-frequency energy
  • Native patch count and diversity—not filename, metadata source, or watermark presence

Guardrails

  • Balance dimensions, formats, codecs, and overlays across real/fake training labels.
  • Do not super-resolve low-resolution images for the forensic branch; hallucinated detail can create a new generator signal.
  • Freeze one threshold before held-out evaluation and measure calibration per quality stratum.
  • Cap worst-case latency and include router/model parameters in the sub-2B total.

Fast experiments that can kill the ideas

Do these before integrating either idea into the main training pipeline.

Experiment A · watermark counterfactual

  1. Create a held-out, source-balanced 2×2 set: real/fake × visible-mark absent/present. Add the same licensed synthetic overlays—logos, signatures, translucent stock text—to both labels.
  2. For naturally marked fakes, create paired crop/inpaint versions. Keep both members in the same evaluation group, never across train/test.
  3. Compare baseline, watermark-tag-only, naïve fusion, and fusion trained with watermark counterfactual consistency.
  4. Report AUROC/BAcc at a frozen threshold plus the score shift for paired add/remove interventions.
  5. Kill condition: fusion loses on unmarked unseen generators, materially raises false positives on marked real images, or large score changes follow only the overlay intervention.

Experiment B · router ablation

  1. Construct equal-count strata by native megapixels and effective quality: clean native, down/up-scaled, JPEG, blur, and composed transforms. Match strata across labels.
  2. Benchmark: fixed cheap model; fixed strong model; literal dimension rule; uncertainty cascade; quality-aware learned router; and an oracle choosing the correct cheapest expert.
  3. Train experts with the same data where possible so routing—not extra data—explains the gain.
  4. Report ROC-AUC, BAcc, TPR at low FPR, calibration, mean/p95 latency, FLOPs, and fraction routed to the strong path per stratum.
  5. Kill condition: the adaptive system does not improve the accuracy–latency Pareto frontier, or routing decisions correlate with label-specific size/codec artifacts.

Smallest useful prototype. No new end-to-end router is needed initially. Use the cheap model's calibrated uncertainty plus a quality floor as a hand-written gate, sweep the exit threshold on a training-only validation set, and compare against always-cheap and always-strong. Learn the router only if that curve shows useful headroom.

Search boundary and future review structure

How this search was run

  1. Searched combinations of AIGC/generated-image detection with visible watermark, fake watermark, logo/text artifacts, shortcut learning, dataset bias, image resolution, downsampling, multi-scale, native patches, routing, cascade, and dynamic inference.
  2. Prioritized primary papers and official proceedings; followed direct references from watermark-interference and any-resolution work into adjacent causal and conditional-compute literature.
  3. Included older work when it directly established a mechanism. Distinguished full-image AIGC detection from face deepfakes, audio, and generic recognition.
  4. Checked claims against the challenge's pure-generation scope, robustness transforms, watermark ambiguity, public-release requirement, and sub-2B cap.

This is a rapid decision review, not a systematic review or proof of absence. The search did not find a controlled paper validating hallucinated visible watermarks as a generator-general cue.
