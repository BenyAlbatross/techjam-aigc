Research report · full-image AI-generation detection

What is actually SOTA in AIGC image detection?

A protocol-aware review for building a robust, sub-2B binary detector. It prioritizes unseen-generator and post-transformation generalization over saturated in-distribution scores, while preserving important out-of-window and adjacent work.

Executive verdict

There is no defensible global rank. Test protocols differ in training source, generator overlap, crop policy, class balance, transformations and metric. The right answer is a Pareto frontier.

Best peer-reviewed broad baselineDDA · 90.7 BAcc

Mean balanced accuracy over 11 benchmarks, with a minimum of 81.4%. The important contribution is dual pixel/frequency alignment of real and fake training pairs, not a novel giant backbone.

Best unified modern auditDDA · 81.6 / 90.2

Accuracy/AP in AIGIBench's standardized retraining table. This is more diagnostic than LOTA's 98.9% or FerretNet's 97.1% under their own protocols; those fall to 77.4% and 79.4% in the same audit.

Best real-world evidenceMIRROR · 91.2 BAcc

Seven in-the-wild sets plus 89.6% on Human-AIGI (27 generators). It is a 2026 preprint, so treat it as the strongest current claim—not settled consensus.

Best curated scores99.6% GenImage

PPM-CLIP on its SD1.4-trained GenImage protocol; LTD reaches 99.54% on a DRCT global subset. These near-saturated values do not establish real-world SOTA.

Best tiny-data resultMPFT · 800 images

98.2% mean GenImage accuracy from an 800-image training set by masking easy generator textures. Preprint; the UFD training-count descriptions conflict.

Best training-free trackRDD · .981 AUROC

GenImage mean, using a three-diffusion-model reconstruction ensemble. WaRPAD is simpler conceptually; DEnD is one-class/OOD; CLIDE needs real calibration exemplars.

Competition implication. A strong, eligible prototype should combine DDA-style controlled data, a frozen/LoRA sub-2B visual foundation encoder, and an original local or transformation-consistency branch. AlignGemini and explanation-heavy VLM systems are scientifically relevant but their 7B-class branch violates this repository's cap. RAW–RGB Alignment is also incompatible unchanged: it treats physically recaptured synthetic images as real, contrary to the challenge's provenance label.

Model recipes and architectural intuition

The eight most actionable families, with enough detail to estimate a reproduction. “NR” means not reported in the audited paper; it is intentionally not guessed.

DDA — make the data causally fair

Recommended spine
Data
118k MS-COCO real images paired with 118k SD2.1-VAE reconstructions. Apply the same composition/JPEG operation to both sides to align pixel semantics and frequency statistics.
Architecture
DINOv2 visual encoder, rank-8 LoRA, 336px input; random crop train, center crop test.
Optimize
LR 1e-4; effective batch 64 (base 16 + accumulation); early stopping; 8×V100 reported.
Output
Binary logit; benchmark reporting uses balanced accuracy.

CV link. This is causal/domain-generalization thinking applied to forensics: if class label correlates with file format, resizing or content, empirical risk minimization learns the nuisance. Matched pairs and frequency alignment perform an intervention on those shortcuts.

MIRROR — remember the real manifold

Preprint
Data
Phase 1: exactly 200k real COCO images. Phase 2: official GenImage SD1.4 split (nominal 162k real + 162k fake), with fake JPEG QF96.
Architecture
Frozen DINO patch encoder; 4,096 orthogonal prototypes; sparse top-k reconstruction; residual/perplexity MLP; DINOv3 LoRA in phase 2.
Idea
Represent authentic image patches with a compact memory. Synthetic patches reconstruct less cleanly or use prototypes with abnormal perplexity.
Cost
Two-phase training; exact phase-2 count and full compute are not explicitly printed.

CV link. A modern one-class anomaly detector: vector quantization, sparse coding and manifold distance. Modeling “real” avoids enumerating future generators, while phase 2 learns where the real-manifold residual is actually discriminative.

Local PDF · arXiv · Code

GAPL — preserve generator modes at scale

CVPR 2026
Data
Prototype phase: 2k each from ProGAN, SD1.4 and Midjourney plus equal real = 12k. Scaling phase: 550k Community-Forensics-small images spanning ~4.7k generators.
Architecture
CLIP ViT-L; PCA; 64 prototypes in 128D; cross-attention matching; two-stage LoRA.
Optimize
Two RTX 4090s reported. Full learning-rate schedule is in the PDF/code.
Result
90.4 Acc / 94.9 AP over six benchmarks and 55 subsets.

CV link. A binary “fake” class is not unimodal. Generator-aware prototypes turn it into a mixture model/metric-learning problem, preventing thousands of generator domains from destructively averaging into one centroid.

Local PDF · Code

PPM-CLIP — a distribution over decisions

CVPR 2026
Data
Separate standard UFD, GenImage-SD1.4 and DRCT protocols; absolute counts are omitted in the paper (nominal public totals: 720k, 324k, 473k).
Architecture
CLIP ViT-L/14; rank-4 LoRA on layers 12–23; conditional normalizing-flow prompt distribution; real/fake prompt repositories; frequency-selected patch contrast.
Optimize
1 epoch, Adam LR 1e-4, batch 48, 224px random crop; K=10 flow steps, 4 Monte Carlo samples.
Result
98.8 UFD, 99.6 GenImage, 95.72 DRCT mAcc.

CV link. It replaces a single discriminative hyperplane with input-conditioned Bayesian-ish prompt uncertainty. Patch contrast makes the global semantic embedding attend to high-frequency local evidence.

FerretNet / MLEP — local evidence survives semantics

Efficient
Data
Each uses 18k ProGAN fake + 18k LSUN real in each of four categories: 144k total.
Architecture
FerretNet: 1.06M-param dual-path grouped convolutions approximating a 5×5 Markov neighborhood. MLEP: shuffled/resampled patches → multiscale entropy maps → ResNet-50.
Optimize
FerretNet: Adam 2e-4, batch 32, 100 epochs, random 224 crop+flip. MLEP: Adam .002, batch 64, 2×A5000; epochs NR.
Result
Both report 97.1% mean accuracy under their own broad protocols.

CV link. Classic texture analysis and Markov random fields. Destroying spatial semantics is a deliberate invariance: generator/camera-pipeline dependencies remain while object identity disappears. A local branch is an excellent complement to a VFM.

LTD / DoU — use the whole representation

CVPR 2026
Data
LTD: 72k UFD or nominal 473k DRCT. DoU: nominal 324k balanced GenImage-SD1.4.
Architecture
LTD learns raw and adjacent-layer transition discrepancies from frozen CLIP-L. DoU uses cue-specific information bottlenecks, HSIC-like decorrelation and class prompts.
Optimize
LTD: 5 epochs, LR 5e-5, batch 256, RTX4090. DoU: Adam LR 1e-4, batch 512, early stop.
Evidence
Strong curated cross-generator scores; neither yet establishes broad real-world dominance.

CV link. Final-layer embeddings compress away forensic details. LTD probes the feature trajectory; DoU fights rank collapse. Both connect to deep supervision, representation-rank regularization, Barlow-Twins-style redundancy reduction and information bottlenecks.

LTD PDF · DoU PDF

RDD / DID — compare to a generative manifold

Reconstruction
Data
RDD: no detector samples. DID small: 10k LAION real + 10k Kandinsky3 or SDXL fake; large: 40k ImageNet real + 40k ADM fake.
Architecture
RDD debiases pixel and latent reconstruction errors across three diffusion priors. DID reconstructs twice and classifies both first-order residual and second-order difference-in-difference with two ResNet-50s.
Result
RDD .981 mean GenImage AUROC; DID 94.55–96.42% small cross-set average and 99.41% large.
Cost
Multiple diffusion passes per image; calibrating a stable confidence threshold remains necessary.

CV link. Analysis-by-synthesis: distance to a learned natural-image/generator manifold. Debiasing and second differences cancel content-dependent reconstruction error, analogous to control variates and finite-difference nuisance cancellation.

RDD PDF · DID PDF

CPTFormer / SDID — fuse frequency and semantics

Robustness
Data
CPTFormer: ProGAN 2/4-class ForenSynths, 80% pristine unpaired + 20% JPEG-QF40 paired; count NR. SDID: official GenImage or DRCT split; count not restated.
Architecture
CPTFormer: CLIP RGB/phase interaction and multi-domain adapters. SDID: DINOv2 RGB LoRA + ResNet-101 on neighboring-pixel-relation images with contrastive/distillation losses.
Result
CPTFormer 79.3% quality-aware GAN mean; SDID 96.1% on CO-SPYBench.
Tradeoff
More branches and compute; phase robustness is narrow, while neighbor-pixel cues may be transform-sensitive.

CV link. Fourier phase carries geometry and is relatively stable under magnitude-changing compression. Semantic and residual streams are complementary “what” versus “how formed” experts; gating/distillation manages their scale and alignment.

Benchmark anatomy

The benchmark is part of the model claim. Counts are images, not paired prompts, unless stated otherwise.

GenImage · static cross-generator anchor

  • 2,681,167 total: 1,331,167 real ImageNet and 1,350,000 fake; 1,000 semantic classes.
  • 8 generators: Midjourney v5 (1024), SD1.4/1.5 and Wukong (512), GLIDE/ADM (roughly 256), VQDM (256), BigGAN (128). Exact native outputs then enter detector preprocessing.
  • Per generator/class: 1,350 fakes, normally 1,300 train + 50 test. Common protocol trains only SD1.4 and tests all eight.
  • Tasks: cross-generator, cross-class, degraded images and few-shot. Main metric is accuracy.

Failure mode: dated generators, ImageNet/source coupling and near-saturation. Always state crop vs resize and whether the seen generator is included in the mean.

UFD / ForenSynths / AIGCDetect · protocol family

  • Canonical 4-class training: car, cat, chair and horse; each has 18k ProGAN fake + 18k LSUN real = 144k total. The larger source dataset is often quoted as 720k.
  • Tests commonly span 19–20 subsets: GANs, perceptual-loss/low-level methods and diffusion models.
  • Metrics: per-source accuracy and AP, then macro mean. Some papers use 2-class, 4-class or full training.

This is not one immutable benchmark. “UFD accuracy” is meaningless without the training categories, test subset list, resize/crop policy and class threshold.

AIGIBench · modern unified stress test

  • 25 evaluation subsets, 215k images: 107,500 fake + 107,500 real, derived from the living repository's corrected counts. The original paper counts contain errors.
  • Groups: 6 GAN noise-to-image, 7 diffusion T2I, 5 GAN deepfake, 5 personalized diffusion, plus SocialRF and CommunityAI.
  • Generators include SDXL, SD3.5-L, DALL·E 3, Midjourney v6, FLUX.1-dev, Imagen 3, InstantID and IP-Adapter.
  • Balanced real sources from FFHQ, CelebA-HQ and OpenImagesV7. Most subsets are 4,500+4,500; corrected exceptions are documented in the living repository.
  • Train I: 72k ProGAN-4 fake + 72k matched real = 144k. Train II adds 72k SD1.4 fake + matched real = 288k total. Tests JPEG Q50, Gaussian noise σ=4 and 0.5× nearest-neighbor down/up sampling.
  • Reports Acc, AP, real accuracy and fake accuracy; includes unified retraining.

Most useful current controlled comparison. The face/editing subsets extend beyond this challenge's pure-generation target, so retain a pure-T2I slice.

AI-GenBench · temporal generalization

  • 360k balanced: 180k synthetic from 36 generators ×5k, plus 180k real.
  • 80/20 split: 288k train and 72k evaluation; 4k/1k per generator with matched real counts.
  • 9 chronological windows ×4 models, from 2017 CycleGAN to 2024 FLUX.1 Dev/Schnell.
  • Past → next and past → all-future evaluation; average AUROC/accuracy over next windows.

The best conceptual test of “future generators,” but its time axis stops in 2024 and it is not a severe transmission/recapture suite.

RRDataset / RRBench · transformations that hurt

  • 20k base: 10k real + 10k fake across critical news/humanitarian and everyday scenes.
  • Critical fakes: 24k prompts, 48k SD3.5-Large/FLUX candidates, 6k retained. Everyday adds SD3.5, FLUX, DALL·E 3, SD1.4/1.5, Midjourney, Chameleon and older GANs.
  • Every image is passed through one of 8 platforms (Telegram, WeChat, Facebook, QQ, WhatsApp, X, Instagram, Tinder), 2–6 cycles.
  • Separate recapture: scan print, photograph print, screen and projection.
  • Reports real/fake accuracy; best audited detector reaches 89.59%.

Excellent deployment stress test. Recheck redistribution/license terms for every real source before using it for training.

NTIRE 2026 · strongest deployment protocol

  • 294,500 images: 108,750 real + 185,750 fake; 42 T2I generators from 2022–26 and 36 transform types.
  • Train ≈277k with 20 open generators/12 transforms. Validation, hard validation, public and private test introduce held-out models and progressively harder transformations; each test is 2.5k balanced.
  • Robust half of each evaluation split receives 1–5 composed distortions: blur/noise/JPEG, crop/downscale, color/tone, perspective, repeated and neural compression, watermark insertion/removal and adversarial attack.
  • Primary metric: distorted-half ROC-AUC; secondary: clean ROC-AUC. Winner MICV averages .9723 robust / .9974 clean.

Best hidden robustness evidence, but outside data was allowed and winners use huge committees. Ant explicitly uses 2×DINOv3-7B; these systems are ineligible under the sub-2B challenge cap.

Other essential slices

  • Synthbuster: 1k RAISE real + 9k diffusion fake from 9 generators; high-resolution, modern T2I, useful for training-free AUROC.
  • Chameleon: 14,863 real + 11,170 human-hard fake images, 720p–4K. Generator identity is unknown and web source/codec can confound labels.
  • Community-Forensics eval: 25k/25k, 21 diffusion sources; training corpus scales to 4,803 generators.
  • WildFake: 3,570,724 images (1,013,446 real, 2,557,278 fake), many GAN/diffusion/other generators; random within-source split is not unseen-generator testing.
  • AIGCDetectBenchmark: standard 360k LSUN real + 360k ProGAN fake training; 17 evolving balanced test subsets. Native resolution/source shortcuts remain.
  • CO-SPYBench: 22 recent generator subsets and semantic/pixel stress; useful for SDID/CO-SPY.
  • Percept-Lens: meta-audit across 39 public datasets, 7,129,395 images; not a single new dataset or directly train/test leaderboard.

Leakage rule. The demonstration-only validation split in this repository must never become training data or a model-selection oracle. Deduplicate by source image and semantic near-duplicate before splitting; keep generator families and transformation chains group-disjoint where possible.

A practical training specification

This is a research recommendation, not a requirement from the challenge brief. It is designed to be small enough for a hackathon, public-releaseable and informative under ablation.

240k–400k

Core controlled pairs

50% authentic; 50% pure generated or VAE-reconstructed. Match prompts/content, output dimensions, codec, color mode and file-writing pipeline across labels. Keep source-image groups intact. A DDA-scale 236k corpus is already credible.

4 families

Generator balance

Within fake: ~20% GAN/upsampling, 35% U-Net diffusion, 30% DiT/flow-matching, 15% autoregressive/commercial where licensing permits. Sample generators uniformly first, then images, so popular engines do not dominate.

30–40%

Hard transformed views

Apply label-independent JPEG/WebP, resize kernels, blur, mild noise, crop, screenshot-like recompression and color conversion. Compose 0–3 transforms; keep pristine views. Do not make one transform label-specific.

≤1B

Backbone + local branch

Frozen DINOv2/CLIP/PE-class encoder with LoRA, plus an original lightweight local-dependency or cross-layer-consistency head. Calibrate a single AIGC probability. Avoid a 7B VLM and avoid copying a pretrained detector.

5 folds

Evaluation axes

Report generator-held-out, family-held-out, real-source-held-out, transformation-held-out and temporal/newest-generator results. Include clean, single-transform and composed-transform strata with bootstrap confidence intervals.

6 metrics

Operating behavior

AUROC and AP for ranking; BAcc and F1 at a frozen threshold; TPR at 1% FPR; expected calibration error/Brier score. Always expose real accuracy and fake accuracy to reveal a biased constant predictor.

Highest-value original contribution: learn when semantic, local-residual and transformation-consistency cues are trustworthy, while using controlled pairs to ensure the gate cannot read file-format or content shortcuts.

Search method, boundaries and audit notes

Concise but exhaustive procedure

  1. Fixed the strict first-publication window to 29 Aug 2025–29 Aug 2026; included older papers only when foundational, groundbreaking or required to understand a current branch.
  2. Seeded from Awesome-AIGC-Detection, then traversed references and shared benchmarks around CNNSpot/ForenSynths, UnivFD, DIRE, GenImage, DRCT and AIDE.
  3. Forward-scanned NeurIPS 2025, ICCV 2025, WACV 2026, AAAI 2026, CVPR 2026/Findings and recent arXiv; searched for temporal, real-world, compression, recapture, one-class and training-free evaluations.
  4. Read primary PDFs for dataset counts, split inheritance, preprocessing, backbone, tuning method, compute and headline tables. “Not reported” remains NR. No number was inferred silently.
  5. Ranked evidence by: unseen generator family → real-world/transformation breadth → peer review/reproducibility → score. Author-protocol scores were never merged into one arithmetic leaderboard.

Scope

In scope: binary classification of fully synthetic versus authentic still images, without watermarks.

Adjacent and labeled: deepfakes/personalized generation benchmark slices; image-conditioned editing; VLM explanation/reasoning; real-only RAW pipelines.

Excluded from recommendations: watermark/SynthID reliance, video-only methods, test-label adaptation, >2B final models, or methods that redefine recaptured synthetic provenance.

Cutoff-sensitive items: a venue date may fall in-window while the first arXiv version does not (IAPL); forthcoming ACM MM'26 work is labeled as such; preprints are not presented as peer-reviewed.

Bottom line. Architecture still matters, but the frontier's clearest result is that evaluation and data construction dominate. Before inventing a complex detector, reproduce three controls: a modern frozen-VFM linear head, DDA-style aligned pairs, and a small local-statistics model. Any proposed novelty should beat all three on family-held-out and transformed data at one frozen threshold.
