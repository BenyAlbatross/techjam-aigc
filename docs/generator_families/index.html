Read this first

“All generators” is a taxonomy problem, not a name-collecting problem

There are thousands of checkpoints, fine-tunes, LoRAs, and product aliases. Listing each would be obsolete immediately and would hide the distinctions that matter for detection. This report covers canonical architecture families, historically important systems, generator lineages common in detection benchmarks, and major current open or API families.

Mechanism

How pixels are produced

Adversarial upsampling, token prediction, iterative denoising, latent-space denoising, rectified flow, or native multimodal generation. This is the strongest first-level grouping for held-out evaluation.

System

A generator can be a stack

DALL·E 2 maps text to a CLIP latent, decodes with diffusion, then upsamples. Imagen uses a language encoder plus cascaded pixel diffusion. One product can leave several kinds of trace.

Variant

Adapters are modifiers

DreamBooth, LoRA, ControlNet, T2I-Adapter, and IP-Adapter usually reuse a base generator. They shift subject, style, layout, or conditioning without defining a new foundation.

ArchitectureThe backbone: U-Net, convolutional GAN, DiT, decoder-only transformer.
ObjectiveThe learning rule: adversarial loss, token likelihood, denoising, or flow matching.
SamplerThe inference path. DDIM can sample a DDPM-family model; it is not necessarily separately trained.
ConditionerA text encoder, class label, edge map, pose, or reference steers the renderer.

Challenge boundary. This atlas focuses on fully synthetic still images. Translation/editing systems appear because benchmarks contain them, but partially edited images are outside the stated target. The <2B rule constrains the submitted detector, not a larger generator used only to create properly licensed training data.

Seven useful buckets

The shortest accurate map of the field

The important move is not simply GAN → diffusion. The field repeatedly changes the representation being modeled—pixels, continuous latents, or discrete codes—and the network or objective used to model it. Modern systems often combine columns.

1. GAN

A generator makes an image in one pass while a discriminator learns to reject it.

ProGAN · BigGAN · StyleGAN · GigaGAN

Question: sharp, fast, controllable images without collapse?

2. VAE / VQ

An encoder compresses images; a decoder reconstructs them; VQ uses a codebook.

VQ-VAE · VQGAN · SD autoencoders

Question: what compact representation preserves detail?

3. Autoregressive

Predict the next pixel or visual token, usually with a causal transformer.

PixelCNN · DALL·E 1 · Parti · Emu3

Question: can images scale like language?

4. Pixel diffusion

Iteratively remove noise in RGB, often with a U-Net and super-resolution cascade.

DDPM · ADM · GLIDE · Imagen

Question: stable training with GAN-level fidelity?

5. Latent diffusion

Compress RGB, denoise the smaller continuous latent, then decode to pixels.

LDM · SD 1/2 · SDXL · Cascade

Question: affordable high-resolution diffusion?

6. DiT / flow

A transformer processes latent patches; newer systems learn rectified-flow velocity.

DiT · SD3 · FLUX · PixArt · Sana

Question: transformer scaling and shorter paths?

7. Native multimodal

One model understands and emits interleaved text/image representations.

Chameleon · GPT Image · Qwen · Hunyuan

Question: one model to understand, plan, edit, and render?

2014–2017

Make synthesis work

GANs sharpen samples; VAEs learn latents; ProGAN reaches megapixel faces; VQ-VAE creates discrete codes.

2018–2020

Scale and control

BigGAN scales class synthesis, StyleGAN exposes style space, and DDPM makes diffusion competitive.

2021–2022

Text becomes the interface

DALL·E tokenizes images; GLIDE, Imagen, and DALL·E 2 diffuse; LDM makes open high-resolution models practical.

2023–2024

Transformers replace U-Nets

DiT, SD3, PixArt, and FLUX add transformer scaling and flow. Adapters and few-step distillation proliferate.

2025–2026

Generation becomes multimodal

Current systems combine reasoning, references, typography, editing, and multi-turn revision.

Decision support

What this map says you should work on

The challenge requires generalization from old Stable Diffusion to newer diffusion transformers under transformations. The highest-value use of this atlas is a family-aware data and evaluation design, not a 48-way attribution classifier.

A practical experiment sequence

  1. Build a generator manifest. Store version, base, VAE, sampler, steps, guidance, adapter, prompt, resolution, date, format, and license.
  2. Split by lineage, not random image. Near-identical checkpoints must not leak. Hold out whole branches such as SDXL, FLUX, or token-autoregressive systems.
  3. Match content and real sources. Pair prompts with licensed real images; align resolution and codec; prevent “COCO=real / LAION=fake.”
  4. Freeze clean and transformed protocols. Use the brief’s JPEG, blur, resize, noise, jitter, and crop settings.
  5. Report by mechanism. Show metrics by family, model, transformation, and native resolution; one aggregate can hide a total DiT failure.

Recommended novelty target

Model the fake class as a mixture of formation mechanisms while learning a stable real-image manifold. Combine a modern semantic backbone with local residual/frequency evidence, then use generator-family-aware prototypes or domain balancing.

GAN upsampling, VAE decoding, diffusion denoising, token decoding, and API post-processing do not promise one universal fingerprint.

Never train on the demonstration-only WildFake DALL·E Advanced / COCO validation split. Review every data and API output license before public release.
