Executive decision

Conditional go after substantial simplification.

Keep the two-stage authentic anchor. Build one frozen DINO-family reference branch, begin with a simple cosine-centroid dictionary, add one small residual interpreter and one lightweight native RGB/residual forensic expert, then use a regularized out-of-fold logistic stacker. Trainable Q/K/V attention memory, learned trust routing, test-time interventions, a new 40–60M forensic transformer, covariance fusion, and an all-DDA positive distribution are isolated ablations after the complete baseline exists.

1. Problem and design thesis

The challenge asks for a confidence score separating purely AI-generated images from authentic images after JPEG, blur, resize, noise, colour jitter, crop, and possibly composed redistribution. AI-edited and partially composited images are outside the main target. Hidden generators may differ sharply from the training generators.

A one-stage binary classifier minimizes training error:

h* = arg minh E(x,y)∼Ptrain[ℓ(h(x),y)].

That objective does not distinguish origin evidence from shortcuts. If real files are JPEG and fake files are PNG, codec can solve the task. If all fake samples use one decoder, that decoder can become the definition of AI. A larger network may learn the wrong rule more confidently.

Alternative2 imposes an asymmetric training sequence:

θreal = arg minθ Ex∼Preal[Lreference(x;θ)];   freeze θreal;   φ* = arg minφ E(x,y)[Ldetect(y;φ,zθreal(x))]. Authentic samples define the coordinate system. Real and fake samples later teach how to interpret deviations, but cannot rewrite the reference.

2. Two-stage ML intuition

2.1 Learn a stable support before fitting a changing opponent

Imagine authentic features form a curved region. Today’s fake images sit to its right. A binary classifier draws a convenient line between them. A new generator may appear above or left of the authentic region and land on the old “real” side. The classifier learned where yesterday’s fakes lived, not the shape of authentic support.

The reference branch does not prove an image is fake. It supplies a stable coordinate system: an authentic explanation and the remaining residual. Stage 2 learns that some residual directions represent rare-but-real content while others repeatedly accompany generation. The overall detector is therefore supervised; the memory constrains the reference, not the final decision.

2.2 Dictionary intuition

The memory is a learned dictionary, not an image database or recurrent network. A spell checker uses valid words to construct the closest legitimate explanation and highlights what remains unexplained. It still needs a second rule to separate a typo from a legitimate rare name. Here:

  • prototype vectors are the dictionary of common authentic patch features;
  • sparse attention constructs an input-specific authentic explanation;
  • the difference between observation and explanation is the residual;
  • a supervised head distinguishes suspicious residuals from benign rare-real variation.

2.3 Why restrict capacity?

An unrestricted autoencoder can reconstruct anomalies too. Alternative2 limits the reference with real-only learning, top-k retrieval, and prototype-redundancy control. Too little capacity underfits authentic diversity and causes false positives. Too much capacity explains generated anomalies and causes false negatives. Memory size and sparsity are empirical knobs.

2.4 Why retain a forensic branch?

DINO-like features emphasize semantic and structural information. A native patch expert can retain local RGB and high-pass evidence destroyed by global resizing. Yet forensic traces can disappear after JPEG, blur, or resize. The two branches are useful only if their errors are complementary and the fusion does not trust a destroyed signal.

4. Stage 1: learn the authentic reference

4.1 Frozen patch representation

A single license-compatible DINO-family encoder maps an image into patch tokens:

F = Eg(x) ∈ RN×D.

At 224 pixels a ViT produces roughly two hundred spatial tokens, depending on patch size. Special/register tokens are excluded from reconstruction. The same encoder remains frozen after Stage 1 so the coordinate system cannot drift away from the learned memory.

4.2 Stage 1A: committed cosine-centroid memory

Reviewer consensus. First fit 512–1,024 MiniBatch k-means centroids to normalized, subtype-balanced authentic patch tokens. Retrieve top-k 16–32 centroids by cosine similarity, apply softmax to those scores, and reconstruct from the weighted centroids. This fixed dictionary is the guaranteed reference. Promote the learned Q/K/V memory described below to Stage 1B only if cached-token smoke tests pass throughput, centroid/prototype use, authentic-versus-native-fake reconstruction gap, and hard-real-FPR gates.
f_i=L2Norm(LN(E_g(x)_i)),   s_ij=f_i^T m_j,   a_i=softmax(TopK(s_i)/τ),   f̂_i=∑_j a_ij m_j.

The centroids themselves have no learned activation, ReLU, or sigmoid. Softmax turns the selected cosine scores into interpolation weights. Stage 1A has no neural optimization loss: k-means estimates the dictionary, and real-only validation chooses K, top-k, and temperature τ.

4.3 Stage 1B: optional trainable prototype memory

The memory is a parameter matrix:

M ∈ RK×D,   M=[m1,…,mK]T.

For patch i and prototype j:

qi=WqLN(fi),   kj=WkLN(mj),   vj=WvLN(mj).
sij=qiTkj/√d,   ai=softmax(TopK(si)),   f̂i=Wo∑jaijvj.

The important activation is softmax over selected prototypes. Memory values are signed embeddings; they have no ReLU or sigmoid. Layer normalization stabilizes scale. Top-k routing gives gradients only to selected entries for that query.

4.4 Optional learned-memory loss

Lref=meani||fi−f̂i||22 +λdivLdiv+λuseLuse.
  • Reconstruction: authentic tokens should have sparse explanations.
  • Diversity: sampled pairwise cosine repulsion discourages duplicate prototypes.
  • Usage monitoring: detects dead or monopolizing prototypes; a weak load-balancing penalty is optional.
Ldiv=meani≠j[max(0,cos(mi,mj)−c)]2.
Why not claim exact orthogonality? If K exceeds D, K vectors in D dimensions cannot all be mutually orthogonal. The MIRROR term ||MMT−I|| is then a diversity pressure with a nonzero lower bound, not an achievable constraint.

5. Memory implementation and outputs

5.1 Optional learned-memory forward pass

# F: [B, N, D] frozen DINO tokens; M: [K, D] learned prototypes
q = Wq(layer_norm(F))                         # [B,N,d]
k = Wk(layer_norm(M)); v = Wv(layer_norm(M)) # [K,d]
scores = einsum("bnd,kd->bnk", q, k) / sqrt(d)
values, indices = topk(scores, TOP_K, dim=-1)
weights = softmax(values, dim=-1)             # [B,N,TOP_K]
selected_v = gather_rows(v, indices)
F_hat = Wo(sum(weights[...,None] * selected_v, dim=-2))
R = F - F_hat                                 # [B,N,D]

Implement prototype scoring in chunks and gather only selected values. Compute attention logits and entropy in FP32 even if cached tokens are BF16.

5.2 Retrieval statistics

smax,i=maxjaij,   Hi=−∑jaijlog(aij+ε),   ri=||fi−f̂i||2.

Pool residual mean, standard deviation, 90th percentile, maximum, attention-entropy mean/variance, maximum-attention mean, and the fraction of patches exceeding a threshold fitted on held-out real data. High entropy is uncertainty, not a fake label; rare authentic patches can also be uncertain.

6. Stage 2: supervised evidence

6.1 Reference residual head

Freeze the encoder, memory, and projector. Train only the residual interpreter on real examples that were not used to fit the memory, native fully generated examples, and a limited auxiliary DDA stream. This is supervised outlier interpretation, not a pure one-class detector. It can still learn fake-specific shortcuts, so it must beat a direct classifier on the exact same frozen tokens.

6.2 Native forensic expert

native image
 → deterministic spatial + texture-aware patches, one 192/224 scale
 → matching RGB and fixed high-pass residual patches
 → lightweight pretrained/no-early-downsampling CNN
 → patch logits
 → mean + standard deviation + 90th percentile
 → z_for and patch disagreement u_for

RGB and high-pass residual are the MVP. Block DCT is one later ablation. Fourier phase, neighbour relations, a 40–60M from-scratch transformer, learned attention aggregation, and heteroscedastic covariance are removed from the committed build.

6.3 DDA as auxiliary boundary exposure

Full DDA creates a VAE reconstruction, matches frequency/format, then mixes real and reconstructed pixels:

xmix=rpixelxreal+(1−rpixel)xsyn.

This is useful as a difficult near-real counterfactual, but it is not a literal native sample of the competition’s purely-generated class. Begin with only 10–20% DDA examples among fake slots, sourced from Stage-2 real lineages. Prefer an auxiliary ranking loss:

Lpair=softplus(m−z(xDDA)+z(xreal-source)).

Never place DDA samples in Stage 1, calibration, or the primary locked evaluation. Native fully generated images across diffusion, DiT, autoregressive, and relevant GAN families remain the principal positives.

7. Reliability and the gate

7.1 Two different “gates”

Memory attention selects prototypes for one patch. TRACE-RX reliability operates later and asks whether a whole expert remains usable. These are different mechanisms.

ak(x)∈[0,1] is a conditional trust/routing weight, not a calibrated probability that evidence survived and not an extra fake score.

7.2 Passive observable inputs

  • JPEG/block-strength and blur estimates;
  • high-frequency energy and image dimensions;
  • reference residual dispersion and retrieval entropy;
  • forensic patch disagreement;
  • expert disagreement magnitude;
  • optionally, response to one selected mild intervention.

Group-level branch survival remains a diagnostic:

d′(k,t)=[μAI(k,t)−μreal(k,t)]/√{[σ²AI(k,t)+σ²real(k,t)]/2},   ρ(k,t)=d′(k,t)/(d′(k,clean)+ε).

7.3 Why the initially proposed gate target is rejected

A tempting target compares clean and transformed BCE loss. It is invalid as a sole reliability definition:

  • an expert wrong on both views with equal loss would look perfectly reliable;
  • a new transform shortcut that improves loss would also look reliable;
  • margin shrinkage mixes calibration with information survival;
  • a clean counterpart is unavailable for an already redistributed deployment image.

Availability is latent and not uniquely identifiable from a single endpoint. Therefore the deliverable model has no learned gate: it gives passive reliability features directly to a regularized stacker.

7.4 Optional conditional trust-router experiment

quality/uncertainty vector q
 → LayerNorm → Linear(Q,64) → GELU → Dropout(0.1)
 → Linear(64,K_experts) → independent sigmoid

If attempted, experts freeze first. Use grouped cross-fitting. Optimize final fused BCE through the router; use group survival and out-of-fold per-expert correctness or regret only as weak regularizers and diagnostics, never as ground-truth availability. Exclude signed logits, source, and generator identity initially. Hold out an entire transform family. Retain the gate only if it beats static stacking beyond paired-bootstrap uncertainty and does not worsen worst-real FPR.

Independent sigmoid is required rather than softmax because all experts can be unavailable.

7.5 Interventions

A small response to JPEG q95 can mean robust evidence or evidence already destroyed by earlier compression. A live signal may also change. Interventions are therefore not causal survival tests. Begin with none. Test at most one mild operator only after passive stacking works, with a fixed latency budget and an unseen-transform evaluation.

8. Fusion, uncertainty, and calibration

The original generalized least-squares formula assumes commensurate unbiased logits and a stable error covariance. Those assumptions are not established. Use out-of-fold, regularized logistic stacking:

v=[zref,zfor, residual summaries, Hattention, Vpatch, qJPEG, qblur, log H, log W].

A one-hidden-layer GELU MLP is a single nonlinear ablation. Raw-logit GLS is not a default, but covariance remains both a diagnostic and a predeclared fusion ablation, specified below. After every architecture choice freezes, fit temperature T on an independent calibration set:

pAI(x)=sigmoid(zfusion(x)/T).

The inference API always returns a numeric score. “Insufficient evidence” may be a reporting overlay, never a missing prediction or third class.

8.1 Why the original covariance formula is not the default

The original generalized least-squares estimator was:

ẑ=[aTΣ−1z]/[aTΣ−1a].

This is principled only under a model such as zk=akz*+εk, with zero-mean errors on a common scale and a stable covariance Σ. The reference and forensic logits have different meanings, scales, calibration, and transformation responses; signal destruction can preserve, reverse, or shortcut a logit rather than merely attenuating it. The phrase “expert residual error” must also be defined before covariance is estimable. Directly inverting covariance of raw logits can amplify small eigenvalue errors and produce extreme or negative weights.

Decision boundary. Do not restore naïve raw-logit GLS. Do retain covariance analysis and two stabilized covariance-aware fusion ablations now that the reduced architecture has only two experts.

8.2 Define covariance on cross-fitted calibrated errors

Freeze both experts and generate lineage-safe out-of-fold predictions. Within each fusion-training fold, independently calibrate each expert and form:

pik=sigmoid(zik/Tk),   eik=yi−pik.

Estimate covariance only from predictions made on records not used to fit that expert or its fold calibration:

Σ̂e=[1/(N−1)]∑i(ei−ē)(ei−ē)T.

Apply shrinkage and diagonal loading before any optimization:

Σ̃=(1−λs)Σ̂e+λsdiag(Σ̂e)+εI.

Record condition number, bootstrap confidence intervals for each covariance entry, and weight stability. Report class- and transformation-stratified covariance diagnostically, but do not fit separate group matrices initially: groups are too small and the deployment transform is unknown.

8.3 Covariance ablation A: constrained probability blend

minw wTΣ̃w   subject to   wk≥0,   ∑kwk=1.

This is the stabilized analogue of minimum-variance combination. Calibration makes the two inputs more comparable; shrinkage stabilizes Σ; non-negativity prevents unexplained sign reversals. Refit final expert calibrators and weights without touching the locked set.

8.4 Covariance ablation B: covariance-regularized logistic stacking

L(w,b)=BCE[y,b+wTz̃]+λcovwTΣ̃w+λ2||w||22.

This is the preferred covariance experiment. It preserves discriminative stacking while penalizing combinations that rely heavily on noisy, correlated expert errors. Standardize logits using fusion-training statistics only. Select λcov and λ2 through grouped inner cross-validation; λcov=0 recovers ordinary ridge stacking.

9. Data, lineage, and shortcut controls

9.1 Roles and independence

A master, prompt siblings, duplicate component, DDA derivative, and every transformed view stay in one partition. Derivatives are observations, not independent samples. Within authentic expert-training masters:

  • Rreference: a dedicated real-only pool used to fit and validate Stage 1;
  • Rsupervised: a lineage-disjoint pool used by Stage 2 and as the only source of DDA pairs.

If data is scarce, cross-fit memories to generate out-of-fold residuals. Do not let the residual head distinguish in-memory records from unseen real records.

9.2 Authentic support

COCO is not “reality.” Balance photographs, screenshots, scans/documents, digital artwork, conventional CGI, computational-photography outputs, and redistributed media. Hold out entire authentic sources and report subtype FPR. Use a shared bank initially; a learned subtype router can introduce another false-positive mechanism.

9.3 Class-neutral preprocessing

  • Run metadata/codec/size-only probes before neural training.
  • Canonicalize or matched-reencode classes while retaining a raw-view ablation.
  • Apply Stage-2 robustness transformations symmetrically to both labels.
  • Generate training transformations on the fly; fix evaluation transforms deterministically.
  • Train Stage 1 on clean plus a controlled amount of transformed authentic data; compare a clean-only memory.
  • Never use the organizer DALL-E/COCO demonstration set for selection.

11.2 Metrics

  • ROC-AUC, average precision, and balanced accuracy because the official metric is unresolved;
  • pAUC over a predeclared 0–5% FPR interval for development selection;
  • TPR at 1% and 5% FPR as operational diagnostics with Wilson/exact intervals;
  • worst generator, authentic subtype, source, and journey metrics;
  • Brier score and calibration curves;
  • master-clustered paired bootstrap intervals for component deltas;
  • latency and memory for every intervention configuration.
Power warning. Five hundred calibration real masters give only about five observations in a nominal 1% tail. Increase the authentic calibration pool to several thousand if possible. Do not tune many architecture choices on TPR@1% FPR or claim production-grade tail control from the locked cohort.

11.3 Removal rules

Remove a component if its improvement vanishes on unseen generators, low-FPR pAUC, or paired confidence intervals; if it increases worst authentic-subtype FPR; or if latency-adjusted gain is negligible. A sub-point single-seed gain is not evidence. Run three seeds for the finalist where time permits.

12. Two-colleague review

The requested reviews were performed in two roles. The red-team colleague audited the design against the organizer brief, original TRACE-RX, DDA, MIRROR, robustness evidence, low-FPR statistics, feasibility, and competition novelty. The broad-ML colleague independently assessed the factorization, memory mechanics, gate identifiability, representation drift, calibration, and simpler controls, then received the red-team findings for reconciliation.

12.1 Red-team conclusion

No-go as first proposed; conditional go after reduction. The red team identified five critical faults: full DDA blurs the pure-generation label; a COCO-like memory can reject rare authentic subtypes; the BCE-difference gate target does not identify survival; unconstrained encoder adaptation invalidates a frozen memory; and the complete architecture cannot be honestly selected at 1% FPR or finished in 24 hours.

It also flagged MIRROR-replication risk. A 4,096-prototype, top-128 DINO memory with real-only reconstruction, residual/perplexity evidence, and a binary head is recognizably prior work. The defensible innovation is the experimentally demonstrated integration with complementary native evidence and carefully constrained reliability—not the memory alone.

12.2 Broad-ML conclusion

Keep the factorization; simplify mechanics. The outside view connected Stage 1 to nominal-support methods such as PatchCore and Stage 2 to supervised outlier exposure. It agreed that the memory is a useful inductive bias but not a guarantee of causal evidence, and that a frozen-encoder compact memory plus static OOF fusion is the identifiable experiment. The learned gate should be demoted until it can beat strong passive controls.

13. Final decision and comprehensive modifications

Proceed with the modified TRACE-RX-Alternative2. Its committed scientific contest is a ladder: direct frozen global classifier → real-reference residual → real-reference plus one forensic expert → optional reliability conditioning. The model is rejected if the memory cannot beat an identical-feature direct head or if it harms authentic long-tail FPR.

13.1 Real-reference modifications

  1. One frozen, license-compatible DINO encoder; no simultaneous three-backbone search.
  2. Commit first to fixed K=512–1,024 cosine centroids with top-k=16–32 and softmax temperature.
  3. Promote K=1,024/top-k=32 trainable Q/K/V attention only after throughput, utilization, reconstruction-gap, and hard-real-FPR smoke gates pass.
  4. For learned memory, use k-means initialization, normalized tokens/prototypes, chunked attention, sampled cosine diversity, and prototype-usage monitoring.
  5. Disjoint Stage-1 and Stage-2 authentic lineages or cross-fitted residuals.
  6. Subtype-balanced authentic support and held-out authentic sources.
  7. No Stage-2 encoder drift. A later LoRA requires memory refitting or a separate frozen memory encoder.

13.2 Forensic and DDA modifications

  1. Replace the custom five-modality transformer with a lightweight RGB/high-pass patch CNN.
  2. Use fixed patch aggregation; DCT is the only initial modality ablation.
  3. Keep native fully generated positives dominant; start DDA at 10–20%, not 25–50% or all-DDA.
  4. Use DDA mainly through paired ranking/downweighted auxiliary supervision and report it separately.
  5. Canonicalization and transformations are class-neutral across the entire dataset.

13.3 Reliability and fusion modifications

  1. Delete the BCE-loss-difference target. Describe optional gate outputs as conditional trust/routing weights, not ground-truth availability probabilities.
  2. Make regularized OOF logistic stacking with passive quality/uncertainty inputs the default.
  3. Remove naïve raw-logit GLS as the default; retain F3 constrained shrinkage blending and F4 covariance-regularized stacking as explicit ablations.
  4. If tested, train independent-sigmoid routing using final fused BCE, with weak group survival and cross-fitted correctness/regret only as regularizers; hold out a transform family.
  5. Use no test-time intervention initially. Add at most one only after measured low-FPR/worst-transform gain under a latency budget.

13.4 Evaluation and claim modifications

  1. Make the direct frozen-VFM classifier and same-token residual head mandatory controls.
  2. Increase authentic calibration to several thousand masters where possible.
  3. Select with broad metrics and 0–5% pAUC; report 1% TPR with intervals rather than optimize everything around ten tail observations.
  4. Use master-clustered paired bootstrap deltas, authentic-subtype FPR, unseen generators/sources, every official transform, and a few predeclared chains.
  5. Open the locked test once after weights, calibration, and thresholds freeze.
  6. Cite MIRROR, DDA, PatchCore/outlier-exposure intuition, and perturbation prior art plainly. Do not claim invention of their mechanisms.

13.5 Final minimum viable system

one frozen DINO-family encoder
 + one fixed real-only cosine-centroid memory (K=512–1,024, top-k=16–32)
 + one small GELU residual/retrieval head
 + one lightweight native RGB/high-pass forensic expert
 + passive quality and uncertainty features
 + regularized out-of-fold logistic fusion
 + independent temperature calibration

optional only after the complete system works:
 learned Q/K/V memory; covariance-aware fusion; conditional trust routing; one mild intervention; DCT;
 constrained adapter followed by memory refitting

This is a stronger research design because it can fail informatively. If the memory adds nothing, the frozen baseline survives. If the forensic expert is brittle, the reference model survives. If reliability conditioning is non-identifiable, static fusion survives. Architecture components earn their place through incremental, out-of-domain evidence.
