1. Challenge contract and architectural thesis

The task is binary, image-level classification of purely generated versus authentic images. AI editing and partial compositing are outside the stated focus. Hidden evaluation may include old and new generator families and JPEG, blur, resize, noise, color jitter, crop, and chains of transformations.

The original thesis was: instead of fitting the moving distribution of fake artifacts, retrieve a context-appropriate authentic reference and classify the unexplained residual. Three intuitions support it:

Stable anchor

Fake labels never alter the authentic reference memory.

Conditional comparison

A night scene should not be reconstructed from an undifferentiated mixture of documents, portraits, and landscapes.

Secondary evidence

Distance and entropy enter fusion; neither alone declares an image fake.

2. Relationship to the original TRACE-RX

The original TRACE-RX proposes a global VFM, a 40–60M native forensic tower, authentic prototypes, inference interventions, and availability/variance/covariance fusion. Its enduring strengths are lineage-safe partitions, transform-survival analysis, unseen-source and generator groups, authentic false-positive control, calibration, and a locked test. Alternative3 retains those scientific safeguards while simplifying the model.

3. Concepts and ML intuition

Semantic key

A semantic key is a normalized centroid in the global VFM feature space. It is an address, not a text label and not necessarily a human category. Keys answer where should the memory look?; patch prototypes answer what authentic visual structure is supported there?

image → global vector c → nearest authentic semantic keys → open routes → authentic patch prototypes

Authentic-reference support

A patch has high support if a sparse combination of real-only prototypes approximates it. Low support might indicate synthetic structure, but it can equally indicate rare authentic content. Support therefore remains an auxiliary feature.

VICReg/BYOL-style consistency

VICReg and BYOL align augmented views without ordinary negative examples. VICReg adds variance and covariance terms to prevent collapse; BYOL uses an online predictor and slow target encoder. Neither guarantees preservation of origin evidence. If a transformation destroys it:

I(T(X);Y) < I(X;Y)  ⇒  forcing z(X)≈z(T(X)) can remove provenance information.

The final MVP uses neither full BYOL nor forensic VICReg. Mild semantic-route consistency remains a later ablation.

Small cross-view provenance subspace

The initial plan projected global RGB and forensic representations into a 64–128D common space with opposite-class negatives. A small dimension does not prevent shortcuts; even one dimension supports:

ziglobal=ziforensic=uyᵢ.

This satisfies the loss while encoding codec, source, resolution, content, or other binary shortcuts. The final MVP uses late fusion instead.

A global semantic query selected memory regions. Visual and forensic patches then attended to paired values. Proposed evidence included visual and forensic residuals, retrieval entropy, semantic–forensic disagreement, relation residuals, and contrastive agreement.

The critical flaw. Authentic content and acquisition are not reliably paired. A portrait may be a phone photo, DSLR image, scan, screenshot, or re-encoded upload. Paired-slot disagreement can measure an uncommon but authentic content/source combination rather than provenance.

Clean reconstruction is non-identifiable after destructive transforms

The initial loss compared a transformed query to clean features:

𝓛rec=ΣHuber(sg(Pi(x))−P̂i(T(x)))+λ[1−cos(Pi(x),P̂i(T(x)))]. (5)

If distinct clean forensic signals map to one endpoint, no function can recover both. Under squared loss, h*(x̃)=𝔼[Ffor(X)|T(X)=x̃], a conditional average rather than erased camera evidence. The final design uses same-endpoint support.

Relational residuals are not independent evidence

With P=P̂+E:

PP⊤−P̂P̂⊤=EP̂⊤+P̂E⊤+EE⊤. (6)

A Gram residual is a nonlinear transformation of the same reconstruction error. It is deferred until ordinary mean, tail, variance, and local autocorrelation controls are stable.

Representation losses

𝓛VICReg=λ𝓛invariance+μ𝓛variance+ν𝓛covariance. (7)

Variance prevents constant collapse; it does not ensure provenance. Opposite-class-only cross-view InfoNCE admits the class-collapse solution above. Both leave the hackathon critical path.

7. Colleague reviews and adjudication

Red-team colleague

The red team’s highest risks were authentic-domain coverage, false semantic–forensic pairing, codec/source/content leakage, non-identifiable reconstruction, hackathon scope, insufficient novelty versus MIRROR, cross-view shortcut transfer, and memory overcapacity.

Let S be content, A acquisition, T redistribution, and R forensic representation. The initial paired memory models p(R|S,Y=real), while many forensic cues are better approximated by p(R|A,T,Y=real). The red team therefore required semantic routing only for visual VFM memory and removed paired forensic slots, cross-memory JS, clean forensic recovery, InfoNCE, BYOL, Gram residuals, and test-time writes.

Independent broad-ML colleague

Independent ruling. Narrow further: do not initially build any forensic memory. First prove content-routed visual memory plus authentic quality-conditioned residual calibration. Admit one independent RGB/high-pass branch only if it earns complementary low-FPR value.

The reviewer also required master-disjoint memory/null/fusion subsets, quality variables used only for normalization, median/MAD calibration with shrinkage, repeated selection around 5% FPR while still reporting 1%, and pre-registered entry and kill gates.

9. Final joint decision and comprehensive modifications

Proceed with the modified TRACE-RX-Alternative3. Its core is a frozen VFM, a real-only content-routed visual prototype memory, sparse observed-endpoint comparison, authentic quality-conditioned residual normalization, and regularized logistic stacking. The forensic branch is independent and optional.

Exact computation

c(x)=Eglobal(x)/||Eglobal(x)||₂,   pi(x)=Epatch,i(x)/||Epatch,i(x)||₂. (8)

Fit spherical k-means keys using only authentic memory-building masters:

{sj}=argmin Σx∈Dmemrealminj||c(x)−sj||₂²,   αj=ec⊤sⱼ/τˢ/Σuec⊤sᵤ/τˢ. (9)

Fit patch prototypes inside each semantic region from clean and independently transformed authentic endpoints. Query only the open regions:

ℓiℓ=pi⊤mℓ/τP+γlog(αgroup(ℓ)+ε),   aiℓ=TopKSoftmax(ℓiℓ). (10)
p̂i=normalize(Σaiℓmℓ),   di=1−pi⊤p̂i. (11)

This is the only cross-attention in the MVP. Memory is frozen; test inputs never write.

Authentic quality-conditioned calibration

q(x)=[qblock,qblur,qnoise,qHF-rolloff]. (12)

Estimate blockiness, blur (Laplacian/Tenengrad), noise (wavelet-MAD), and high-frequency rolloff. Cluster a disjoint authentic null subset into quality states. Do not pass q directly to the classifier.

μb=median(d | Q=b,Y=real),   σb=1.4826·median(|d−μb| | Q=b,Y=real). (13)
d̃i=clip((di−μ̃b(x))/(σ̃b(x)+ε),−8,8). (14)

Shrink small cells toward global authentic statistics. This is nuisance normalization, not likelihood estimation.

Evidence and output

m(x)=[mean(d̃),Q.90(d̃),std(d̃),f95,H̄P,HS,dS]. (15)

The seven features describe residual level, upper tail, spatial heterogeneity, authentic-tail fraction, patch retrieval concentration, route ambiguity, and finite semantic support. None is calibrated uncertainty.

u(x)=[zglobal(x),m(x),𝟙for-admittedf(x)],   s(x)=b+w⊤u(x),   pred(x)=sigmoid(s(x)/T). (16)

Fit L2 logistic stacking on a dedicated fusion split and temperature on calibration only. Emit image_path and pred for every image.

Optional forensic expert

After the memory ablations, test ImageNet-pretrained ResNet-18 with stride-1 first convolution, no max-pool, six-channel RGB plus r(x)=x−Gσ=1*x, and twelve uniform native 224×224 patches. Aggregate mean, 90th percentile, and standard deviation of patch logits. Train with label-symmetric transforms. Do not route, align, or give it memory.

Training phases and ablation ladder

  1. Protocol/confound gate: licenses, lineage, duplicates, matched codec/size, symmetric journeys, nuisance probes, held-out codec/resizer.
  2. A0: frozen VFM + linear head.
  3. A1: A0 + real kNN/shrinkage Mahalanobis.
  4. A2: A0 + unconditioned sparse memory.
  5. A3/A3-R: semantic routing versus random/shuffled routes.
  6. A4: authentic quality-conditioned residual calibration.
  7. A5: optional independent RGB/high-pass branch.
  8. Fusion/calibration: static stacking, temperature, then locked test once.

Memory construction, authentic null fitting, and supervised fusion use master-disjoint subsets. With 80,000 licensed masters, prefer roughly 64k expert/memory, 5k fusion, 5k development, 5k calibration, and 1k locked test.

Entry and kill gates

Select repeatedly with normalized partial AUC over FPR [0,0.05] and TPR@5%; still report TPR@1%. Define δmin=max(1 normalized-pAUC point, 2×finalist seed SD).

Defensible if measured

  • Memory uses only authentic training images.
  • Content routing restricts visual reference comparison.
  • Residuals are normalized against similar authentic quality.
  • The named component improves the named held-out metric with interval.
  • The model is below 2B and returns continuous confidence.

Claims to avoid

  • The memory learns the real-image manifold.
  • Memory distance is forgery probability.
  • Keys recover causal human categories.
  • The model reconstructs erased sensor detail.
  • Entropy is calibrated uncertainty or attention is explanation.
  • The detector certifies authenticity or every future generator.

Approval statement. TRACE-RX-Alternative3 is approved for experimentation in this modified form. Every claim now has a control, an entry gate, an authentic-harm constraint, and a kill condition. If routing fails, use unconditioned memory. If memory harms held-out authentic sources, remove it. If forensics is not complementary, ship the smaller model.

The success criterion is not that every module survives. It is that the team can state exactly which hypothesis survived a valid test.
